# AishaTulegen — ViewModels және валидация

Айша Тілегеннің Абай университетіндегі 3-курс, 4-апта тапсырмасы. ASP.NET Core MVC көмегімен пайдаланушыны тіркеу, деректерді бірнеше деңгейде тексеру және қолданушыларды басқару үлгісі.

## Жоба мақсаты

Домен моделін ViewModel-ден бөлу, Data Annotations, браузерлік және серверлік тексерулерді көрсету. Тіркеу деректері SQLite дерекқорына сақталады; құпиясөз ASP.NET Identity `PasswordHasher` арқылы хэштеледі. Құпиясөз де, оның хэші де көріністерге берілмейді.

## Технологиялар

- C# және .NET 8
- ASP.NET Core MVC, Razor
- Entity Framework Core 8 және SQLite
- ASP.NET Identity PasswordHasher
- jQuery Validation және jQuery Unobtrusive Validation
- Data Annotations, `IValidatableObject`, `ModelState`

## Құрылым

```text
Controllers/       Басты бет пен қолданушы әрекеттері
Data/              EF Core дерекқор контексті
Models/            Домен моделі (User)
ViewModels/        Тіркеу, панель, тізім және мәлімет көріністері
Validation/        Құпиясөздің арнайы тексеру атрибуты
Migrations/        SQLite бастапқы миграциясы
Views/             Қазақша Razor көріністер
wwwroot/           Бейімделгіш CSS, JavaScript және жергілікті кітапханалар
```

## Орнату және іске қосу

Жоба бумасында .NET 8 SDK орнатылған болуы керек.

```powershell
dotnet restore
dotnet build
dotnet run
```

Қолданба көрсеткен жергілікті URL мекенжайын браузерде ашыңыз. Қосымша іске қосылғанда EF Core `Migrations` ішіндегі миграцияны автоматты түрде орындап, жоба түбірінде `aisha-tulegen.db` файлын жасайды. Бұл файл жергілікті дерек және `.gitignore` арқылы Git-ке қосылмайды.

Жаңа миграция жасау үшін EF CLI 8-нұсқасын уақытша орнатып, содан соң командаларды орындаңыз:

```powershell
dotnet tool install --global dotnet-ef --version 8.0.22
dotnet ef migrations add MigrationName
dotnet ef database update
```

## Негізгі мүмкіндіктер

- Басты панельде нақты SQLite есептегіштері, тексеру тәсілдері және соңғы тіркелімдер көрінеді.
- Тіркеу формасында аты-жөні, пошта, жас, құпиясөз және қайталау өрістері бар.
- Қолданушылар тізімінен аты-жөні немесе электрондық пошта арқылы іздеуге болады.
- Қолданушының жеке бетінде тек жария мәліметтері көрсетіледі.
- Пошта қайталануын қолданба тексеруімен қатар дерекқордағы бірегей индекс қорғайды.

## Валидация мысалдары

- `Required`, `StringLength`, `Range`, `EmailAddress`, `Compare`, `RegularExpression`
- `StrongPasswordAttribute`: бас әріп, кіші әріп, сан және арнайы таңба
- `IValidatableObject`: аты мен тегі болуын және кәмелет жасын тексеру
- Клиенттік ережелер ASP.NET Core validation helper-лері және unobtrusive скрипттер арқылы қосылады.
- POST әрекеті `ModelState.IsValid` нәтижесін міндетті түрде тексеріп, қайталанған поштаға `ModelState.AddModelError` қосады.

## Тексеру

Тіркеу формасын қолмен тексеру тізімі:

1. Бос форманы жіберу — міндетті өрістер көрсетіледі.
2. Қате пошта пішімі мен жас ауқымынан тыс мәнді тексеру.
3. Қысқа, сансыз, бас/кіші әріпсіз немесе арнайы таңбасыз құпиясөздерді тексеру.
4. Құпиясөздерді әртүрлі енгізу.
5. Бір пошта мекенжайымен қайта тіркелу.
6. Дұрыс мәліметпен тіркеліп, тізім мен іздеу нәтижесін тексеру.

Автоматты компиляцияны тексеру:

```powershell
dotnet build
```
